# نشر ورقة الآن على Netlify بدون انتظار حد Vercel

> هذه استضافة بديلة **مستقلة** عن Vercel. لا تمسح الموقع القديم ولا تحذف حسابات Supabase ولا ترفع أسرار API إلى GitHub.

## التجهيز الذي تم في المستودع
- `netlify.toml` يحدد بناء صفحات الموقع ومسارات وظائف الخادم.
- `scripts/build-netlify.mjs` ينسخ ملفات HTML/JS الخاصة بالواجهة فقط إلى `dist/`، ولا ينشر SQL أو مكتبة الخادم أو أسرار البيئة.
- `netlify/functions/api.mjs` يوجّه `/api/config` وباقي المسارات إلى واجهات ورقة الموجودة؛ لا يحتاج تعديل روابط JavaScript.
- التطبيق يظل يستخدم **نفس** قاعدة Supabase الحقيقية ونفس مفتاح Gemini، بعد إعداد متغيرات البيئة على Netlify.

## 1 — Netlify Free
1. افتح https://app.netlify.com/start ثم اختار `Import an existing project → GitHub`.
2. اربط مستودع `adammohamedsalaheldin65-hue/ag-creative`.
3. Branch: `main`.
4. **Base directory**: `waraqa-demo` (مهم، لا تختار جذر المستودع).
5. **Build command**: `node scripts/build-netlify.mjs` إذا لم يُكتشف من netlify.toml.
6. **Publish directory**: `dist`.
7. **Functions directory**: `netlify/functions` (يتحدد تلقائياً من الملف).

لا تنشر الموقع قبل إضافة متغيرات البيئة، إن كانت شاشة Netlify تسمح بإضافتها أثناء الإنشاء. وإذا انتهى النشر قبل إضافتها، فأضف المتغيرات ثم أنشئ Deploy جديداً.

## 2 — إعداد Environment Variables في واجهة Netlify
المتغيرات نفسها المستخدمة في موقع ورقة على Vercel (القيم السرية لا تحفظ في GitHub):

| Variable | القيمة |
| --- | --- |
| `SUPABASE_URL` | رابط Supabase الصحيح `https://vhyygvbqemhqirbcycev.supabase.co` |
| `SUPABASE_PUBLISHABLE_KEY` | Supabase publishable/anon key الخاص بالمشروع |
| `SUPABASE_SERVICE_ROLE_KEY` | service role/secret server key من Supabase، Functions فقط |
| `GEMINI_API_KEY` | مفتاح Gemini الموجود في Google AI Studio، سيرفر فقط |
| `GEMINI_MODEL` | نفس اسم الموديل المستخدم على Vercel (اختياري) |
| `SUBSCRIPTION_ENABLED` | `true` إذا كان ملف `subscriptions.sql` مطبقاً |
| `ALLOW_ANONYMOUS_AI` | `false` |
| `STUDENT_PORTAL_ENABLED` | `true` **فقط** بعد تطبيق `supabase/student_portal.sql` على نفس قاعدة ورقة |
| `SUBSCRIPTION_ADMIN_TOKEN` | نفس رمز إدارة المدفوعات الآمن الموجود على Vercel، إذا كنت تستخدم لوحة اعتماد الإيصالات |
| `INSTAPAY_DESTINATION`, `INSTAPAY_ACCOUNT_NAME`, `SUBSCRIPTION_PRICE_EGP`, `PREMIUM_PRICE_EGP` | انسخها فقط لو كانت مخصصة على Vercel؛ للقيم غير المعدلة توجد افتراضيات في التطبيق |

مهم جداً: لا تضع المفاتيح السرية في محادثة عامة، ولا في كود GitHub، ولا داخل `netlify.toml`. ابحث عن `Site configuration → Environment variables` واضغط إضافة وحفظ.

## 3 — تحديث رابط تأكيد البريد على Supabase
عندما يعطيك Netlify رابط `https://xxxx.netlify.app` افتح Supabase الصحيح:
`Authentication → URL Configuration → Redirect URLs`.

أضف هذين الرابطين إلى القائمة، **ولا تمسح روابط Vercel القديمة**:
- `https://xxxx.netlify.app/**`
- `https://xxxx.netlify.app/student.html**`

استخدم نطاق مشروعك الحقيقي بدلاً من `xxxx`.

## 4 — الاختبار
1. افتح `https://xxxx.netlify.app/api/config`. يجب أن يعود JSON ويتضمن `authConfigured:true`, `aiConfigured:true`, `subscriptionEnabled:true`, `studentPortalEnabled:true`.
2. افتح `https://xxxx.netlify.app/student.html` وتأكد أن الصفحة تظهر.
3. أنشئ حساب طالب، أكد البريد، سجّل دخولك، ثم جرّب ملخصاً قصيراً.
4. سجّل الدخول كمعلم من الصفحة الرئيسية، وجرّب نشر امتحان **اختيار من متعدد** موجود في السجلات؛ انسخ الرابط وجربه بحساب الطالب.
5. راجع نتائج الطالب من المعلم ونتائج الامتحان من الطالب.

## حدود وتكلفة البديل
Netlify Free خطة مجانية بحد **300 usage credits شهرياً** على نظام التسعير الحالي، وتشمل الاستضافة وNetlify Functions. يمكن أن يتوقف الموقع حتى بداية دورة جديدة لو انتهت حصة الخطة المجانية. إعداد مفاتيح Gemini الحرص على بقائها دون فوترة مدفوعة منفصل عن رسوم Netlify.
الموقع يعمل بوظائف Node محددة بزمن، فلو استغرق Gemini أكثر من مدة الوظيفة قد تحتاج إعادة المحاولة أو تقصير نص الدرس.
الموقع القديم على Vercel يظل منفصلاً ويمكن العودة له لاحقاً.

## إذا ظهرت أخطاء
- Netlify `404` على `/api/config`: راجع `Functions → api` وتحقق من وجود Netlify Function والـ Base directory الصحيح.
- `aiConfigured:false`: راجع مفاتيح Supabase وGemini على Netlify ثم Deploy من جديد.
- `studentPortalEnabled:false`: تأكد من `SUBSCRIPTION_ENABLED=true`, `STUDENT_PORTAL_ENABLED=true` ونجاح تنفيذ SQL على المشروع الصحيح.
- صفحة تسجيل الدخول لا تعود بعد تأكيد البريد: أضف Netlify domain إلى Supabase Redirect URLs.
- فشل نشر على Netlify: اعرض أول رسالة خطأ من Deploy log، ولا تضغط Redeploy بشكل متكرر بلا معرفة السبب.
