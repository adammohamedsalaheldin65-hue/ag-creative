# تشغيل ورقة بدون دفع من المعلم

## الحالة الحالية

الرابط الموجود على GitHub أو HTMLPreview يعرض واجهة تجريبية فقط ولا يمكنه تشغيل API بأمان.
النسخة المحلية تحفظ سجلات كل معلم في متصفحه فقط، وتسجيل الدخول الحالي تجريبي وغير آمن للإطلاق العام.

## ربط AI مركزي بدون رسوم على المعلم

1. أنشئ مشروعًا خاصًا للمنصة في Google AI Studio واحصل على GEMINI_API_KEY ضمن الحصة المجانية إن كانت متاحة لحسابك وبلدك.
2. لا تنشر المفتاح في HTML أو GitHub ولا ترسله إلى المعلمين.
3. انشر نفس مستودع GitHub كـ Vercel Project جديد مع **Root Directory** = `waraqa-demo`، وFramework Preset = Other.
4. ضع `GEMINI_API_KEY` في Environment Variables الخاصة بالاستضافة، ويفضّل استخدام مفتاح غير مربوط بفوترة مدفوعة في مرحلة التجربة لتجنب المصروفات غير المقصودة.
5. اختبر `/api/config` على نطاق الاستضافة الجديدة؛ بعد تفعيل المفتاح سيعرض `aiConfigured:true`، وزر توليد الأسئلة من الصور يعمل من **نفس النطاق**.

## تحذيرات مهمة قبل استقبال معلمين فعليين

- لا تنشر خدمة التوليد للاستخدام العام قبل إضافة **تسجيل دخول آمن** و**تحديد معدل الاستخدام لكل معلم**، وقيود مشتركة على الحصة. الكود الحالي نموذج أولي ولا يحتوي على الحماية الكافية للإنترنت العام.
- Google Gemini free tier لها سقوف استخدام وقد تمنع الخدمة مؤقتًا عند استهلاك الحصة. لا توجد خدمة مجانية بلا حدود مضمونة.
- وفق شروط Google، محتوى free tier يمكن أن يستخدم لتحسين الخدمات ويحتمل أن يطلع عليه مراجعون. لا ترفع بيانات طلاب خاصة أو صورهم أو أوراقهم الشخصية.
- يجب على المعلم مراجعة جميع الأسئلة والإجابات قبل الطباعة. خرائط الدراسات والرسومات ينبغي فحصها والتأكد من مطابقتها للكتاب.
- تصدير شرح فيديو بأصوات مدمجة داخل الملف يتطلب خدمة إضافية مستقلة؛ الاستوديو الحالي ينتج مشاهد مبسطة ولا يعد بفيديو رسوم متحركة احترافي تلقائيًا.
