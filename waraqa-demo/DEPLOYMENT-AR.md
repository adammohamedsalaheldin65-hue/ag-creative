# ورقة – نسخة قابلة للنشر للمعلمين

## ما الذي يعمل؟
- تخصيص امتحان لجميع المواد الدراسية المدرجة، الأسئلة والدرجات ونموذج الإجابة وطباعة PDF عبر Print.
- سجل امتحانات مربوط بحساب المعلم بفضل Supabase Auth + RLS، وصور الدرس تُخزن بمسارات خاصة في Supabase Storage.
- Gemini AI يقرأ صور الدرس مباشرة عند تفعيله من خادم Vercel؛ لا يطلب من المعلم دفعًا أو حسابًا منفصلًا.
- مشاهد شرح كرتونية مبسطة؛ **ليست** فيديو رسوم متحركة احترافي، وتصدير WebM قد يكون صامتًا؛ تشغيل النطق يعتمد على متصفح الجهاز.
- يمكن تجربة نموذج من نص الدرس بدون AI في وضع المعاينة غير المتصل.

## النشر الأول
1. أنشئ **مشروع Supabase جديد مخصص لورقة**، حتى لا تختلط بياناته بأي مشروع سابق.
2. افتح SQL Editor وشغّل الملف \`supabase/schema.sql\`؛ فعل تأكيد البريد الإلكتروني في Authentication.
3. أنشئ API Key في [Google AI Studio](https://aistudio.google.com/apikey). تحقق من توفر الحصة المجانية لحسابك وبلدك. **لا تضع مفتاح Gemini في GitHub أو في JavaScript الواجهة**.
4. اربط مستودع GitHub \`adammohamedsalaheldin65-hue/ag-creative\` بمشروع **Vercel جديد**، واضبط \`Root Directory\` على \`waraqa-demo\` و\`Framework Preset\` على \`Other\`.
5. من Vercel > Project > Settings > Environment Variables، أضف:
    - \`GEMINI_API_KEY\`: مفتاح Gemini السري (الخادم فقط).
    - \`GEMINI_MODEL\`: \`gemini-2.5-flash-lite\` (اختياري).
    - \`SUPABASE_URL\`: رابط مشروع Supabase.
    - \`SUPABASE_PUBLISHABLE_KEY\`: مفتاح Supabase publishable العام.
    - \`SUPABASE_SERVICE_ROLE_KEY\`: مفتاح Supabase السري للخادم فقط.
6. انشر المشروع وتأكد من \`/api/config\` (يجب أن يعرض \`authConfigured:true\`, \`aiConfigured:true\`). جرّب إنشاء حساب جديد، ثم امتحان صغير بصورة واضحة.

## بدون دفع من المعلمين
- حد افتراضي **5 عمليات AI يوميًا لكل معلم**، و**100 عملية إجمالًا للمنصة يوميًا**. توليد الصور والفيديو فعليًا ليس مجانيًا بلا حدود؛ إذا انتهت الحصة المجانية قد تتوقف الخدمة إلى تجددها.
- تفعيل اشتراك مدفوع لمفتاح الذكاء الاصطناعي قد يسبب رسومًا **على مالك المنصة**. لا تفعل الفوترة إن لم تكن موافقًا على التكاليف.
- Google قد تستخدم بيانات الاستخدام المجاني لتحسين منتجاتها؛ **لا ترفع بيانات شخصية للطلاب** أو أوراق تحتوي بيانات حساسة. افتح شروط Google قبل الإطلاق العام.
- لا تُعتبر الأسئلة دقيقة تلقائيًا؛ يُراجعها المعلم وخصوصًا الخرائط والنحو والاختيارات.

## أمان النسخة
- المفتاح السري محجوب داخل API فقط.
- كل طلب AI يتحقق من هوية المعلم ومن حصة الاستخدام قبل الإرسال للخدمة.
- قواعد RLS تمنع المعلم من رؤية سجلات معلم آخر.
- الصور في Bucket خاص وليست صورًا عامة.
- قد تحتاج إضافة حماية CAPTCHA وإشراف إداري وسياسة خصوصية واضحة قبل الإعلان للمدارس على نطاق واسع.
- بيانات المعاينة المخزنة في نفس المتصفح لا تُنقل تلقائيًا إلى حسابات Supabase.

## اختبار محلي
يمكن فتح واجهة HTML، لكن خدمات الحسابات والذكاء الاصطناعي تتطلب نشر API والبيئة السرية على استضافة خادم. قبل نشرها، يمكنك مراجعة ملفات API بـ Node.js 22+، وتجربة الأجزاء المحلية في المتصفح.
